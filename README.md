# SomaTekisi Car Services - Web Application

## Project Overview
This project is a 5-page website developed for **SomaTekisi Car Services**, built using semantic HTML5 and custom CSS. It provides essential information regarding vehicle maintenance, fleet services, enquiry options, and workshop locations.

## File and Folder Structure
```text
SOMATEKISI CAR SERVICES/
│
├── css/
│   └── style.css         # Main stylesheet for site styling
├── js/                   # Directory reserved for JavaScript scripts
├── images/
│   └── Taxi.jpg          # Image assets used across pages
│
├── index.html            # Homepage (Hero section, intro, call to action)
├── about.html            # About Us (History, mission, vision, team)
├── services.html         # Services offered (Engine service, diagnostics, electrical)
├── enquiry.html          # Enquiry form (Service bookings, fleet, sponsorship)
